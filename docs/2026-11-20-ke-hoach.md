## Task 1. ⛔ Chạy thử embedding e5-small (cổng chặn)

**Mục đích:** xác nhận cách nạp model ở TK mục 3 chạy được, trước khi xây gì lên trên nó.

**File:** `backend/requirements.txt`, `backend/spike_embed.py` (xoá sau task này).

1. Tạo `backend/.venv`. Pin **đúng phiên bản** vào `requirements.txt`:

   - các gói khác lấy bản mới nhất ở thời điểm làm (`pip index versions <gói>`): `fastapi`, `uvicorn`, `python-multipart`, `chromadb`, `rank-bm25`, `pypdf`, `python-docx`, `openpyxl`, `defusedxml`, `openai`;
   - test: `pytest`, `httpx`, `fpdf2`, chỉ dùng để tạo PDF mẫu trong test.
2. Script chạy thử:

```python
from fastembed import TextEmbedding
from fastembed.common.model_description import ModelSource, PoolingType

TextEmbedding.add_custom_model(
    model="intfloat/multilingual-e5-small",
    pooling=PoolingType.MEAN,
    normalization=True,
    sources=ModelSource(hf="intfloat/multilingual-e5-small"),
    dim=384,
    model_file="onnx/model.onnx",
)
m = TextEmbedding("intfloat/multilingual-e5-small")
q = list(m.embed(["query: nghỉ phép năm báo trước mấy ngày"]))[0]
p_hit = list(m.embed(["passage: Người lao động phải gửi đơn ít nhất 03 ngày làm việc trước ngày nghỉ phép năm."]))[0]
p_miss = list(m.embed(["passage: Định mức công tác phí cho chuyến đi trong nước là 500.000 đồng mỗi ngày."]))[0]
assert q.shape == (384,)
assert q @ p_hit > q @ p_miss, (q @ p_hit, q @ p_miss)
print("ok", q @ p_hit, q @ p_miss)
```

**Nếu đỏ:** dừng, báo người dùng, đề xuất chuyển sang `intfloat/multilingual-e5-large` (có sẵn trong FastEmbed, 1024 chiều). Không tự đổi.

## Task 3. `ingest.py`: đọc file và cắt đoạn

**File:** `backend/ingest.py`, `backend/tests/test_ingest.py`.

Đầu ra: `list[Chunk]`, với `Chunk = (text: str, meta: dict)`. `meta` **không chứa giá trị `None`** (TK mục 5).

- `read_pdf(path)`:
  - `pypdf`, mỗi trang một khối, `meta = {"page": n}`;
  - tổng số chữ (bỏ khoảng trắng) bằng 0 thì ném `IngestError("PDF chỉ có ảnh scan, không đọc được chữ")`;
  - PDF có mật khẩu thì ném `IngestError("PDF có mật khẩu")`.
- `read_docx(path)`:
  - duyệt `doc.element.body` để giữ đúng thứ tự đoạn văn và bảng;
  - nhớ tiêu đề Heading 1–3 gần nhất làm `section`;
  - mỗi dòng bảng ghép các ô bằng `; `.
- `read_xlsx(path)`:
  - `openpyxl.load_workbook(path, read_only=True, data_only=True)`;
  - mỗi sheet lấy dòng đầu tiên có dữ liệu làm tên cột;
  - mỗi dòng sau thành `"Cột A: giá trị; Cột B: giá trị"` (bỏ ô trống), `meta = {"sheet": ..., "row": n}`;
  - `import defusedxml` ở đầu module để openpyxl dùng.
- `split(text)`: cắt đệ quy theo `\n\n` → `\n` → `. ` → ` `, đoạn khoảng 500 ký tự, chồng lấn khoảng 100. Viết tay khoảng 25 dòng, không thêm LangChain. Chỉ áp dụng cho PDF và Word, **trong từng trang/mục**, không cắt ngang ranh giới.
- `ingest(path, file_type) -> list[Chunk]`. File hỏng (lỗi bất kỳ từ thư viện đọc) thì đổi thành `IngestError("File hỏng, không mở được")`.

**Test** (file mẫu tạo ngay trong test qua `tmp_path`):
- PDF 2 trang (tạo bằng `fpdf2`) → các đoạn có `page` 1 và 2.
- PDF trang trắng (`pypdf.PdfWriter().add_blank_page`) → `IngestError` đúng câu báo scan.
- Word có đoạn văn trước Heading đầu tiên → đoạn đó **không có khoá** `section`; đoạn sau Heading "4.2 Nghỉ phép" có `section == "4.2 Nghỉ phép"`.
- Excel có dòng tiêu đề + 2 dòng → 2 đoạn, chữ đúng dạng `Loại nghỉ: Phép năm; Báo trước: 3 ngày`, `row` đúng.

- File `.docx` là rác → `IngestError("File hỏng…")`.

## Task 4. `search.py`: embedding, Chroma, BM25, RRF

**File:** `backend/search.py`, `backend/tests/test_search.py`.

- `Embedder`: bọc đoạn `add_custom_model` của Task 1. Hai hàm `embed_passages(texts)` (thêm `passage: `) và `embed_query(text)` (thêm `query: `).
- `Index`:
  - một collection Chroma `PersistentClient(path=DATA_DIR/chroma)`;
  - `add(doc_id, chunks, vectors)` / `delete_doc(doc_id)` / `all_texts()`;
  - `dense(qvec, k=20)`: luôn truyền vector đã tính sẵn, cả khi thêm lẫn khi tìm (`query_embeddings=`), không bao giờ để Chroma tự embed.
- `tokenize(text)`: chữ thường, bỏ dấu câu, tách theo khoảng trắng. **Giữ dấu tiếng Việt.**
- BM25 đổi bằng một lệnh gán:

```python
class Bm25Holder:
    def __init__(self): self.current = (None, [])        # (BM25Okapi | None, ids)
    def rebuild(self, ids, texts):
        bm = BM25Okapi([tokenize(t) for t in texts]) if texts else None
        self.current = (bm, ids)                          # single assignment = atomic swap
```

  `/api/ask` đọc `bm, ids = holder.current` **một lần** ở đầu request.

- RRF:

```python
def rrf(*rankings: list[str], k: int = 60) -> list[tuple[str, float]]:
    scores: dict[str, float] = {}
    for ranking in rankings:
        for rank, cid in enumerate(ranking, start=1):
            scores[cid] = scores.get(cid, 0.0) + 1 / (k + rank)
    return sorted(scores.items(), key=lambda x: -x[1])
```

- `search(question, top=5)`: dense 20 + BM25 20 → `rrf` → 5 đoạn kèm metadata và danh sách từ khoá khớp (các token của câu hỏi có trong đoạn), để giao diện tô màu.

**Test:**
- `rrf(["a","b"], ["a","c"])[0] == ("a", 2/61)`.
- `tokenize("Nghỉ phép, NĂM!") == ["nghỉ", "phép", "năm"]`.
- `Bm25Holder` rỗng không lỗi.
- Test tích hợp `@pytest.mark.slow`, dùng embedder thật và Chroma trong `tmp_path`: thêm 3 đoạn → câu hỏi về nghỉ phép trả đoạn nghỉ phép đứng đầu; `delete_doc` → không còn đoạn nào của doc đó.

## Task 5. Worker index: hàng đợi, thay file, xoá, khôi phục

**File:** `backend/worker.py`, `backend/tests/test_worker.py`.

Đây là phần dễ sai nhất (TK mục 3). Một `threading.Thread` daemon cùng một `queue.Queue` chứa các việc `("index", doc_id)` hoặc `("delete", doc_id)`.

**Việc `index`:**
1. `ingest(tmp_path)` → đặt `progress_total = len(chunks)`.
2. Embed từng lô 32 đoạn → `index.add(doc_id, …)`, cập nhật `progress_done` sau mỗi lô.
3. **Thành công:**
   - nếu có `replaces_id`: `index.delete_doc(old)`, xoá file cũ, `store.delete(old)`;
   - chuyển file tạm vào `files/<thư mục>/<tên>`;
   - `status=ready`, ghi `chunk_count`, rồi `rebuild_bm25()`.
4. **Lỗi bất kỳ:**
   - `index.delete_doc(doc_id)` (dọn đoạn đã ghi dở) và xoá file tạm;
   - `status=error`, `error` = câu báo của `IngestError`, lỗi lạ thì ghi "Lỗi khi index: <tên lỗi>" và log stack trace;
   - **bản cũ không bị đụng tới.**

**Việc `delete`:** `index.delete_doc`, xoá file, `store.delete`, `rebuild_bm25()`.

**`recover()` lúc khởi động**, chạy trước khi worker bắt đầu: với mỗi dòng còn `indexing`:
- `index.delete_doc(id)`, xoá file tạm;
- `status=error`, `error="Bị gián đoạn khi index, hãy tải lên lại"`.

Xong thì `rebuild_bm25()`.

**Test** (embedder giả trả vector cố định để chạy nhanh; Chroma thật trong `tmp_path`):
- index thành công → đoạn có trong Chroma, file nằm đúng chỗ, `ready`;
- `ingest` ném lỗi giữa chừng (ingest giả trả đoạn rồi embedder giả ném lỗi ở lô 2) → không còn đoạn nào của doc, `error`;
- thay file: bản cũ `ready`, bản mới lỗi → bản cũ còn nguyên đoạn và file;
- thay file thành công → chỉ còn đoạn của bản mới;
- `recover()` với một dòng `indexing` có đoạn dở → hết đoạn mồ côi, dòng thành `error`;
- hai file đưa vào hàng đợi → chạy lần lượt (ghi lại thứ tự bắt đầu/kết thúc, không chồng nhau).

**Kiểm:** `pytest backend/tests/test_worker.py` xanh. **Commit:** `feat(backend): single-thread index worker with safe replace and recovery`.
